# Personal Portfolio Website

A responsive personal portfolio website created using **HTML and CSS** to showcase my profile, skills, projects, achievements, certifications, and contact information.

## 📌 Features

* 🏠 Home section with personal introduction
* 👩‍💻 About Me section with personal details and statistics
* 🛠️ Skills section
* 💼 Projects section
* 🏆 Achievements section
* 📜 Certifications section
* 📩 Contact form
* 🔗 Social media links
* 📱 Responsive design using CSS Media Queries
* 🦶 Footer section with additional links

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, Flexbox, animations and responsiveness

## 📱 Responsive Design

CSS Media Queries are used to make the website responsive on different screen sizes. The layout adjusts according to the device width while keeping the original desktop design unchanged.

## 🎯 Purpose

The purpose of this project is to create a professional online portfolio that presents my **technical skills, projects, achievements, certifications, and contact details** in a structured and visually appealing manner.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.

No additional installation or setup is required.
