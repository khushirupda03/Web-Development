Marwadi University Academic Portal

A clean, single-page static portal presenting fundamental academic structures, program maps, and community high points using modern layouts.

## Features

* **Strategic Mapping Overview:** Centralized content covering Core Institutional Vision, Operational Mission statements, and targeted Program Specific Outcomes (PSOs).
* **Navbar Layout:** A top-anchored navigation frame enabling seamless section scrolling on modern displays.

## Tech Stack

* **HTML5:** Semantic structural building block containers.
* **CSS3:** Custom interface variables, flexbox structures, card layout matrices, and native hover behaviors.
