# Flexbox CSS Animation & Gallery

## Aim
To create a bouncing loader animation, photo gallery using CSS Flexbox, and demonstrate flex properties on containers and children.

## Concepts Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Animation
- @keyframes

## Tasks
1. Create a bouncing loader animation.
2. Create a photo gallery using CSS Flexbox.
3. Apply Flex properties to flex containers and flex children.

## Learning Outcome
Learned how to create CSS animations and design flexible layouts using Flexbox.
